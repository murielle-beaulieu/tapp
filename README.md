# tapp
A simple to-do list app built with Express JS and MongoDB

# Features
Create, view, update, and delete user
Create, view, update, and delete tasks
Create, view, update, and delete categories

Get started by signing up as a user
Each user can create tasks and categories
Tasks can be duplicated
Categories can be assigned to tasks

# Tech Stack
Node.js — JavaScript
Express — web framework
MongoDB - document database
Supertest - Testing HTTP
Jest - JavaScript Testing

# Installation
git clone git@github.com:murielle-beaulieu/tapp.git
cd tapp
npm install

# Running the app
npm start

The app will be available at http://localhost:3000 (update the port if yours is different).
